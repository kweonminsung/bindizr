# 🚀 Release: 0.2.0

Bindizr 0.2.0 brings activity, access, and transfer logs into one API and CLI.
Pair it with [Bindizr UI 0.2.0](https://github.com/kweonminsung/bindizr-ui/tree/v0.2.0)
for the matching log views.

## 📦 Distribution

Debian, RPM, and Alpine packages and a container image with the ExternalDNS
adapter are available for amd64 and arm64. The GitHub release includes
`THIRD_PARTY_LICENSES.html`. The Helm chart is published at
`oci://registry-1.docker.io/kweonminsung/bindizr-chart`.

## 📌 Installation (Debian/Ubuntu)

```bash
dpkg -i bindizr_0.2.0-1_amd64.deb    # _arm64.deb on arm64
```

## 📌 Installation (RHEL/CentOS/Fedora)

```bash
rpm -i bindizr-0.2.0-1.x86_64.rpm    # .aarch64.rpm on arm64
```

## 📌 Installation (Alpine)

```bash
apk add --allow-untrusted bindizr-0.2.0-r1.x86_64.apk    # .aarch64.apk on arm64
```

## 📌 Installation (Helm)

Create a database connection secret, then install the chart.

```bash
helm install bindizr oci://registry-1.docker.io/kweonminsung/bindizr-chart \
  --version 0.2.0 \
  --set bindizr.database.existingSecret=bindizr-db-secret
```

See the [Kubernetes guide](https://kweonminsung.github.io/bindizr/deployment/kubernetes/)
for database, secondary, and TLS configuration. To enable the optional web UI,
set `bindizrUi.enabled=true` and `bindizrUi.image.tag=0.2.0`.

## ⚠️ Breaking Changes

- **Clean installation.** Start with a new Bindizr database, including when
  moving from 0.2.0-rc.1. Export and reimport any DNS zone data you want to
  carry forward. Re-create roles, credentials, and other deployment settings
  separately. For signed zones, follow the
  [DNSSEC cutover steps](https://kweonminsung.github.io/bindizr/deployment/migrating/#zones-with-dnssec)
  before switching secondaries.
- **Log endpoints and commands.** Use `GET /logs/activity` and
  `bindizr log activity` in place of `GET /audit`, `GET /logs/audit`,
  `bindizr audit list`, and `bindizr log audit`. A secondary's transfer
  history moves from `GET /secondaries/{name}/transfers` and
  `bindizr secondary transfers NAME` to `GET /logs/transfer?secondary_name=NAME`
  and `bindizr log transfer --secondary NAME`. The `log:read` grant replaces
  `audit:read` and covers all three logs.
- **Log and history fields.** Access and transfer logs use `client_ip` and
  `error_code`. Access entries report `actor`, `requested_at`, and
  `response_code`. Activity and transfer entries use `created_at`.
  Zone versions use `source` and `actor`.
- **DNS and DNSSEC controls.** Use `dnssec_enabled` to filter zones and
  `include_dnssec` to include generated DNSSEC records in listings and exports.
  DNSSEC policies expose `key_layout` (`csk` or `split`), and rollover
  advances through `POST /zones/{name}/dnssec/rollover/advance` or
  `bindizr dnssec rollover advance`. Secondaries use
  `notify_tsig_key_name` and `--notify-tsig-key`.
- **Filters and configuration.** Date range filters use `since` and `until`.
  Zone version queries use `include_signer_only_versions` and
  `from_serial`/`to_serial`. Use `[history] max_days` for zone history and
  `[activity_log]`, `[access_log]`, and `[transfer_log]` for log retention.
  Transfer TLS uses `dns.transfer.tls_required`. The zone default TTL uses
  `dns.zone_defaults.default_ttl`.
- **Metrics.** Update dashboards that use the `type` label on
  `bindizr_xfr_total` to query `kind`. The `table` label on
  `bindizr_pruned_rows_total` now names the current tables.

See the [HTTP API reference](https://kweonminsung.github.io/bindizr/api/) and
the [CLI reference](https://kweonminsung.github.io/bindizr/cli/) for current
fields and flags.

## ✨ New Features

- **Activity log.** Follow management operations and committed DNS changes by
  operation, result, target, or date. The same endpoint returns the operation
  catalog, including operations with no entries yet.
- **Access and transfer logs.** Inspect management requests and DNS updates in
  the access log and AXFR/IXFR attempts in the transfer log. All three logs
  support filtering, sorting, pagination, and independent retention.
- **Web UI.** Browse the three logs from the sidebar and select or clear
  role grant actions by scope. Lists and dialogs adapt to narrow screens.

## 🧹 Fixes & Improvements

- Check both the original and destination record permissions when updating a
  record's identity.
- Improve daemon startup and graceful shutdown, secondary synchronization
  reports, and DNSSEC response handling.
