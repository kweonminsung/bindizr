# 🚀 Release: 0.1.0

> **First stable release.**

## 📦 Distribution

**Debian (.deb)**, **RPM (.rpm)**, and **Alpine (.apk)** packages for
**amd64 and arm64**, a **multi-arch container image** carrying the ExternalDNS
adapter, and the **Helm chart** at
`oci://registry-1.docker.io/kweonminsung/bindizr-chart`.
The GitHub release also includes **`THIRD_PARTY_LICENSES.html`**.

## 📌 Installation (Debian/Ubuntu)

```bash
dpkg -i bindizr_0.1.0-1_amd64.deb    # _arm64.deb on arm64
```

## 📌 Installation (RHEL/CentOS/Fedora)

```bash
rpm -i bindizr-0.1.0-1.x86_64.rpm    # .aarch64.rpm on arm64
```

## 📌 Installation (Alpine)

```bash
apk add --allow-untrusted bindizr-0.1.0-r1.x86_64.apk    # .aarch64.apk on arm64
```

## 📌 Installation (Helm)

With a database connection secret already created:

```bash
helm install bindizr oci://registry-1.docker.io/kweonminsung/bindizr-chart \
  --version 0.1.0 \
  --set bindizr.database.existingSecret=bindizr-db-secret
```

See the [deployment guides](https://kweonminsung.github.io/bindizr/deployment/kubernetes/)
for database secrets, secondary servers, and TLS configuration.

## ⚠️ Breaking Changes

- **Clean installs only.** There is no database or configuration upgrade path
  from the alpha, beta, or release-candidate versions. Preserve any DNS data
  needed for the new installation before replacing an earlier deployment.

## 🧹 Fixes & Improvements

Since **0.1.0-rc.3**:

- Mutation responses report the permissions in effect when the change is applied
- Updated runtime dependencies
