# 🚀 Release: 0.1.0-rc.3

> **Third release candidate.** Every change since **0.1.0-rc.2**: zone
> transfers over TLS, an audit log, every zone of an old primary imported in
> one run, and an Alpine package. Clean installs only — no upgrade path from
> rc.2.

## 📦 Distribution

**Debian (.deb)**, **RPM (.rpm)**, and, new, **Alpine (.apk)** packages for
**amd64 and arm64**, the **multi-arch container image** with the ExternalDNS
adapter, and the **Helm chart** at
`oci://registry-1.docker.io/kweonminsung/bindizr-chart`, each with
**`THIRD_PARTY_LICENSES.html`**.

## 📌 Installation (Debian/Ubuntu)

```bash
dpkg -i bindizr_0.1.0-rc.3-1_amd64.deb    # _arm64.deb on arm64
```

## 📌 Installation (RHEL/CentOS/Fedora)

```bash
rpm -i bindizr-0.1.0_rc.3-1.x86_64.rpm    # .aarch64.rpm on arm64
```

## 📌 Installation (Alpine)

```bash
apk add --allow-untrusted bindizr-0.1.0_rc3-r1.x86_64.apk    # .aarch64.apk on arm64
```

## 📌 Installation (Helm)

```bash
helm install bindizr oci://registry-1.docker.io/kweonminsung/bindizr-chart \
  --version 0.1.0-rc.3 \
  --set bindizr.database.existingSecret=bindizr-db-secret
```

## ⚠️ Breaking Changes

- **Configuration keys moved into sections**: `[api.tls] cert_file`/`key_file`,
  `[dns.nsupdate] tsig_required`, `[dns.transfer] cache_max_records`, and
  `[history] zone_max_days` replace their flat rc.2 names. Environment
  variables follow the TOML path
- **`bindizr dnssec-policy`** is now **`bindizr dnssec policy`**
- **Daemon socket**: a root CLI trusts another user's daemon only on
  `/run/bindizr`, never under `/tmp`
- **Schema replaced**: `audit_log` and the transfer `transport` column are new

## ✨ New Features

- **Zone transfers over TLS** — XoT (RFC 9103) on port 853, with
  `[dns.transfer] require_tls` to close the plain listeners to transfers
- **Audit log** — every token, role, grant, TSIG key, secondary, and DNSSEC
  policy change and zone deletion: `bindizr audit list`, `GET /audit`, under
  the new `audit:read` action
- **Bulk import** — every zone a server serves: `zone import --from-server`
  with `--zones` or `--from-catalog`, or `POST /import`, with a
  [migration guide](https://kweonminsung.github.io/bindizr/deployment/migrating/)
- **Alpine package** — the same binary under OpenRC
- **TLS** — to MySQL and PostgreSQL (`[database.tls]`), and certificates
  re-read on `bindizr config reload`
- **TCP limits** — `dns.tcp_idle_timeout_secs` and `dns.tcp_max_connections`
- **RFC compliance** — the DNS plane was audited against the RFCs it cites and
  its MUST-level gaps closed

## 🧹 Fixes & Improvements

- **Wire values** — TXT bytes, RFC 3597 data, escaped labels, and serial
  wraparound survive every path
- **Dependencies** — rustls 0.23.46 and domain 0.12.3 pick up their security
  advisories
- **Large requests** — ExternalDNS, import, and rollback no longer slow down
  quadratically
- **SQLite** — a row id past the 32-bit range is refused, not truncated
