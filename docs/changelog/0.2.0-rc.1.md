# 🚀 Release: 0.2.0-rc.1

> **First release candidate of 0.2.0.** Every change since **0.1.0**: three
> logs — audit, access and transfer — read one way under `/logs`, and the web
> UI rearranged around them. Clean installs only — no upgrade path from 0.1.0.

## 📦 Distribution

**Debian (.deb)**, **RPM (.rpm)**, and **Alpine (.apk)** packages for
**amd64 and arm64**, a **multi-arch container image** carrying the ExternalDNS
adapter, and the **Helm chart** at
`oci://registry-1.docker.io/kweonminsung/bindizr-chart`.
The GitHub release also includes **`THIRD_PARTY_LICENSES.html`**.

## 📌 Installation (Debian/Ubuntu)

```bash
dpkg -i bindizr_0.2.0-rc.1-1_amd64.deb    # _arm64.deb on arm64
```

## 📌 Installation (RHEL/CentOS/Fedora)

```bash
rpm -i bindizr-0.2.0_rc.1-1.x86_64.rpm    # .aarch64.rpm on arm64
```

## 📌 Installation (Alpine)

```bash
apk add --allow-untrusted bindizr-0.2.0_rc1-r1.x86_64.apk    # .aarch64.apk on arm64
```

## 📌 Installation (Helm)

With a database connection secret already created:

```bash
helm install bindizr oci://registry-1.docker.io/kweonminsung/bindizr-chart \
  --version 0.2.0-rc.1 \
  --set bindizr.database.existingSecret=bindizr-db-secret
```

See the [deployment guides](https://kweonminsung.github.io/bindizr/deployment/kubernetes/)
for database secrets, secondary servers, and TLS configuration.

## ⚠️ Breaking Changes

- **Logs under `/logs`**: `GET /audit` → `GET /logs/audit` (`bindizr log audit`);
  `/secondaries/{name}/transfers` → `GET /logs/transfer?secondary_name=`
  (`bindizr log transfer --secondary`)
- **`audit:read` is now `log:read`**, covering all three logs
- **Configuration**: `[history] max_days` and `[audit_log]`, `[access_log]`,
  `[transfer_log]` replace `zone_max_days` and `audit_max_days`
- **Schema replaced**: `transfers` becomes `transfer_log`; `access_log` is new

## ✨ New Features

- **Access log** — every management API request and nsupdate, with its client,
  credential, and outcome: `bindizr log access`, `GET /logs/access`
- **Transfer log** — every transfer answered, refused, or failed, kept as
  history: `bindizr log transfer`, `GET /logs/transfer`
- **Log settings** — filter, sort, and page all three logs; `save` and
  `max_days` choose what each keeps (`save = "none"` turns one off)
- **Web UI** (bindizr-ui 0.2.0-rc.1) — Logs and DNSSEC as sidebar groups, and
  every listing with its filters and sort on one line

## 🧹 Fixes & Improvements

- **Sorting** — ties follow the sort's direction, and `sort`/`order` ignore case
- **Configuration reference** — fixed-value settings list their values
- **Dependencies** — clap 4.6.8, nix 0.32, axum-server 0.9.1, openssl 0.10.82,
  and the Rust 1.100 build image
