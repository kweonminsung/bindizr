Before production use:
  - Set bindizr.image.repository and bindizr.image.tag if you need a different Bindizr image.
  - BIND9 accepts NOTIFY from any source by default through allow-notify { any; }.
  - Set bindizr.database.existingSecret or bindizr.database.url when using mysql/postgresql.
